# Porting frontier - main source set
#
# Every path listed here is a src/main/java file that has not been ported to
# 1.21.1 yet. sourceSets.main.java excludes each one, so the build compiles only
# what has actually crossed over and every PR in the port stack is green.
#
# This ledger only ever shrinks. A port PR deletes the lines it brought across;
# nothing is ever added back. checkPortingFrontier enforces that against HEAD~,
# and also fails on a listed path that no longer exists, so a rename cannot leave
# a stale line behind. The last PR of the port deletes this file outright.
#
# Sorted, repo-relative, one path per line.
