# The test island - tests whose subject is on the island
#
# A test cannot compile against a class that is still on the island: the island is
# excluded from sourceSets.main and compiled for measurement only, so anything on
# the test classpath cannot see it. Such a test therefore sits on the test frontier
# (porting/unported-test.txt) for exactly as long as its subject sits on the main
# one, and this file names the ones a slice has already brought up to 1.21.
#
# Two things read it:
#   - checkPortingFrontier, for the born-file exception. porting/unported-test.txt
#     only shrinks, except for a file created by the commit that lists it here -
#     the same rule T5 wrote for src/main/java and porting/island.txt, which could
#     never apply to a test because that ledger may only name src/main/java paths.
#     Without it a slice cannot add a new test file at all (T7 §9).
#   - errorBudgetTest, which compiles these files alongside the island against the
#     test compile classpath and reports the errors in them. That is the "island
#     standard" every slice since T5 has claimed by hand, made repeatable.
#
# Invariants, enforced by checkPortingFrontier:
#   - every listed path exists and lives under src/test/java or src/gametest/java
#   - no duplicates
#   - every listed path is ALSO listed in porting/unported-test.txt
#
# Lifecycle: T13 takes these out of both ledgers when the island joins the real
# compile, and the file is deleted with the rest of the machinery.
#
