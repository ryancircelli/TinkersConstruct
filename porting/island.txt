# The island - files under the error budget
#
# The island was library/ + common/ + shared/ + fluids/ + the two root classes, and
# by T19 the content packages too: the ~1470-class core that the rest of Tinkers sits
# on. It could not be ported one file at a time the way the outer packages can, because
# its classes reference each other densely enough that any single-file cut leaves both
# halves broken. So it ported through a deliberate RED stretch: files landed here first,
# compiled with errors, and the errors were paid down until the island was green in one go.
#
# Every path listed here is compiled by the `errorBudget` task with failOnError=false into
# build/errorBudget/classes - a scratch directory that is never packaged. The resulting
# diagnostic counts are compared against porting/errors.json by `checkErrorBudget`, which
# is wired into `check`.
#
# Invariants, enforced by `errorBudget`:
#   - no duplicates
#   - every listed path exists and lives under src/main/java
#   - every listed path is ALSO listed in porting/unported.txt. A file on the island is
#     still excluded from the main source set: it is being compiled for measurement only,
#     and the real build must stay green.
#
# Lifecycle: T4 onwards added paths here as it ported files into the island, and paid the
# budget down. When the budget reached 0 the same PR deleted those paths from
# porting/unported.txt and from this file at once, and the island joined the real compile.
#
# EMPTY AT T22, AND PERMANENTLY. The island reached 0 errors at T21 and T22 flipped all
# 1,473 files out of both ledgers in one commit; `compileJava` compiles them for real and
# the jar carries them. Nothing can re-enter: the only 67 files still behind the main
# frontier are plugin/**, blocked on third-party artifacts rather than on porting errors,
# and they cross whole when T20's dependency work lands rather than through a RED stretch.
# `errorBudget` still runs on every `check` - over zero sources it resolves the Minecraft,
# NeoForge and Mantle classpath and asserts the island is closed, which is the invariant
# worth keeping until this file and the rest of the machinery are deleted with plugin/'s
# frontier entry in the closing slice.
#
# Sorted, repo-relative, one path per line.
